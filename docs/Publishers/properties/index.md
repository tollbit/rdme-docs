# Properties

To get all the benefits of TollBit, including our analytics and bot paywall feature, the first and most important step is to add and set up your properties.

## Getting Started

Follow these steps to set up your property:

1. [Add a Property](adding-a-property) - Create your property in the TollBit dashboard
2. [Verify a Property](verifying-a-property) - Verify ownership through DNS configuration

Once you've completed these steps, you'll be ready to configure integrations and start monetizing your content.
