# Introduction

The TollBit CLI connects your TollBit account to the tools you already use, either a terminal or an AI agent such as Claude Code, Codex or Cursor. Ask questions in plain language and your agent does the work, or run commands yourself and get structured results back.

## What You Can Do

| Capability        | What It Gives You                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Analytics API** | Query your AI traffic data with SQL: which AI bots read which pages, where AI referrals land, and how it all changes day to day.            |
| **Search API**    | Search licensed publisher content across the TollBit network, see how your content appears to AI agents, and check what's ready to license. |

Both APIs are in early access and are enabled per organization. To request access, email [team@tollbit.com](mailto:team@tollbit.com).

# Guides

1. Getting Started: request access, install the CLI, and connect it to your organization.
2. Analytics API: example questions, commands, available data and sample queries.
3. Search API: searching from the dashboard and the CLI, reading results, and checking your content's pricing.
