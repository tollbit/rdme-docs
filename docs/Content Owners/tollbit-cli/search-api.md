The Search API searches licensed publisher content across the TollBit network: the same search AI agents use to find content they can cite and license. Use it to see how your content appears to AI agents, check that your articles are discoverable and ready to license, and compare your coverage with other publishers in the network.

Access: request it at [team@tollbit.com](mailto:team@tollbit.com). Once enabled, you'll see it under CLI → Search API in your dashboard. For installation and sign-in, see Getting Started.
